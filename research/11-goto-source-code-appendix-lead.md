GoTo/Overture相关后续专利US7110993B2的说明书，在Definitions之前/开篇注明：

公开可阅读位置：https://patents.google.com/patent/US7110993B2/en ，开篇Declarations及Definitions。

**不可推出**：已经取得了光盘二进制或所有源代码；它必然是2000年前后生产环境的完整实际系统；代码每个文件均由该案两名发明人亲自开发；该光盘可不经许可直接向GitHub重新分发。现在只有说明书对附录的声明。

## 官方制度背景
USPTO MPEP §608.05(a)（官方）：https://www.uspto.gov/web/offices/pac/mpep/s608.html
- 37 CFR 1.96(c)将“Computer Program Listing Appendix”作为不随专利公报印刷的程序附录；
- MPEP说明公开可用的程序清单副本可经Patent Center获得，也可能按37 CFR 1.19请求；
- 这是一条可查找档案的制度线索，**不证明此具体旧案光盘今天已经数字化可直接下载**。

## 下一轮检索和提取工作
1. 在USPTO Patent Center以申请号US09/915,801（公报US7110993B2）查看Image File Wrapper，检索program listing / CD / appendix / dir_s / artifact sheet。
2. 若在线附件不存在，依据MPEP/USPTO规则确认公开申请材料副本申请渠道、费用与光盘状态；记录请求日期、提供方和访问限制。
3. 取得原件后先建立**安全、版权与完整性检查**：是否仅审查披露用示例，是否含历史系统源文件或测试数据，有无敏感内容；不直接向公开仓库上传原始程序或可能受版权限制的材料。
4. 在许可允许的范围内，仅发表自己的代码结构统计、时间戳谱系、技术功能分类及可复核摘要，验证US6269361与后续案之间**真实工程组织关系**，不以法律家族自动代表代码继承。
5. 如能匹配文件形成时间与当时商业系统工作方式，再连结“书”（技术/组织制度）、“世家”（工程谱系）、“列传”（贡献主体），并主动检查复用/继承/独立实现的反例。
