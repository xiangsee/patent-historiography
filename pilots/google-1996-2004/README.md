# 试验卷：Google 1996—2004

**状态：准备阶段，非全量分析成果。**

## 研究目标
验证“专利+商业史+制度史+纪传体”能否提出并解释常规产品史未充分讲述的早期技术转折。

## 核心题目（暂定）
《谷歌本纪·立业：从网页排序到广告系统》。这是工作标题，不预先认定两项技术足以代表全公司史。

## 本轮研究边界
- 时间窗口：1996—2004，既包括公司成立前的大学技术起点，也覆盖上市时点。
- 技术：搜索/信息排序、相关广告为初始假说，必须由全量检索确认其重要性与其他关键方向。
- 公司：Google Inc.及可证实的关联研发/权利主体，特别处理斯坦福技术许可。
- 对照：同期搜索与广告行业竞争者；具体清单待第一轮史料核验。

## 三个不得偷换的概念
1. Stanford专利的发明/申请/许可，不等于Google当年拥有该专利。
2. 2002年提交申请，不等于2002年已经取得2010年授权的专利权。
3. 两项种子专利只是可查证的叙事起点，不是全量技术聚类或显著性排序。
