# 风险登记表 v0.1

| 风险 | 典型误判 | 缓解方式 |
| --- | --- | --- |
| 事后成功偏差 | 从今天的产品逆推过去必然成功 | 还原当时可见信息、同期竞争者与被放弃路线 |
| 企业归属误差 | 今天的所有人被误作当年发明人/权利人 | 历史主体账簿和有日期的权属事件 |
| 公开滞后 | 近年的申请量看似突然下降 | 删失区间与跨年覆盖审计 |
| 同族重复 | 一件全球申请被算成几十件发明 | 公开简单/扩展同族及去重规则 |
| 代理指标误用 | 专利多=创新强，引用多=商业成功 | 对照商业、技术和行业证据 |
| 没申请专利的创新 | 断言某时期企业没做研发 | 访谈、开源、产品与组织史料交叉查验 |
| 叙事性幻觉 | AI编造人物对话/会议/动机 | 事实卡、时间戳、反证、人工复核 |
| 版权和数据权利 | 公开上传有许可限制的原始库 | 数据白名单、RIGHTS.md、仅发布派生可许可成果 |
| 历史人物隐私 | 无事实基础的个人评价 | 只写可核实的公共职务贡献和必要历史事实 |

风险需要随每一部本纪增补，不能靠通用免责声明取代审查。
