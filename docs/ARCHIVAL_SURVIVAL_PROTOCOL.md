# 《企业史记》档案存续与访问证据规范 v0.7

企业史的史料可见性不能简单等同于技术存在或不存在。专利正文中引用程序附录，只直接证明**文本公开记载了该附录**；还需官方接收证明、介质保管记录、研究者实际获得文件、完整性验证和使用许可。

## 各状态不得自动升级
**文本引用**（已核实）→ **官方接收登记**（未核）→ **实物或电子保管**（未核）→ **研究者取得副本**（未实现）→ **SHA-256及目录完整性检验**（未做）→ **与研发和产品的历史对应**（未做）→ **版权/隐私批准公开**（未做）。

## 具体规则
- HTTP 403、动态网站HTML壳或空检索结果不能自动解释为档案遗失。
- 2001年法定提交和抽查流程须按当年有效版本研究；现行MPEP只是2026年访问指南。
- 原始时点、记录制作/转交时点、公开时点和现代数字化时点必须分开。
- 公开数据库的代码与专利文本不是同一权利许可体系。大规模复制前审查版权、商业秘密、个人信息与安全风险。
- 不执行任何来源不明的脚本、压缩包或二进制；仅进行离线哈希、只读清单和安全静态检查。
- 类比《史记》的史料失传：对不存在、不可获得、未检索、未公开、尚未数字化等状态分开标记。
- 未来若提供文件，应保存访问方式、来源、合法限制、获取时间、SHA-256、文件数、总字节和逐项异常说明；原始文件不得默认放进公开GitHub。
