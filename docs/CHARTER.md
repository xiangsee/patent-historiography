# 研究宪章 / Project Charter

## 使命
将专利当作“尚未确定结果时留下的技术记录”，与组织、商业、制度和竞争史料交叉印证，研究企业能力形成与历史转折。产出既能复核又值得阅读的企业史，而非专利数量排行榜。

## 四个核心问题
1. 某项关键技术能力何时进入企业？是自主形成、收购、联合研发还是许可？
2. 企业在某个时点实际可选择哪些路线？何以形成、改变或终止选择？
3. 技术能力与产品、战略、组织、产业秩序的时间关系如何？
4. 哪些被后来的成功叙事遮蔽的路线、失败和竞争者值得重写？

## 研究对象
企业法人与控制关系、发明与专利族、研发团队和技术轨迹、产品与商业事件、制度/标准与法律变化，以及竞争者。研究应覆盖“技术空间”与“产品空间”，不能把二者等同。

## 最小可发表单元
**一个可解释的历史转折 + 一组可追溯的专利证据 + 至少一类独立的非专利史料 + 反证检查 + 可供一般读者理解的叙事。**

## 成功标准
- 发现至少一个仅看产品或财务史容易忽略的历史联系，并能提供反证路径。
- 以数据或明确的抽样设计支撑“变化”“首次”“持续”“主要”等用词。
- 对当年的时间顺序、权属、当事人意图保持证据边界。
- 文稿不依赖专业读者理解专利分类号即可阅读。
- 数据口径、检索日期、版本、许可限制与判断链条可复查。

## 当前边界
本仓库v0.1.0为方法和史料结构版本；没有完成任何企业的全量专利基线。Google 1996—2004为方法试验卷；完整华为企业本纪是后续候选，并非当前完成项。

## 发布原则
研究陈述分三类：已核实事实、明确的数据推断、可争辩的历史解释。公开章节应标注史料局限与作者观点，必要时同步发布勘误和版本变更。
