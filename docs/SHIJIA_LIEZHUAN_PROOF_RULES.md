# v0.6｜“世家”和“列传”必须分别证明的关系

## 世家：至少五种不同的谱系，不能混在一起
1. **专利权属谱系**：申请、优先权/继续申请、转让、合并、许可；按原始发生日/登记日分别记录。法律文件本身不能证明技术实际实施。
2. **技术问题谱系**：分类、说明书和解决的问题相似，只能提出比较研究问题。
3. **知识影响谱系**：有同期书信、论文或当事人回顾证明观察、借鉴或竞争学习；不等于抄袭、侵权或正式转让。
4. **工程实现谱系**：需要设计文档、源码、产品/标准文档或可核验的工程师证言来证明某一技术路径实际被采用。
5. **组织传承与分叉**：需要团队、组织和工程系统连续性证据，还应观察被暂缓或后来重启的技术路线。

## 列传：人物证据分级
L1 专利署名；L2 同时代公开任职或贡献记录；L3 同行评议论文、访谈、证言对具体贡献的独立叙述（注意发表年与利益相关）；L4 多方交叉核验的工程制品或同期档案，才支持详细研发分工。

**同源并不能变多证**：两篇Google相关人士论文加Google简介，仍主要是内部叙述。外部大学托管某人简历，不自动意味着大学验证了其全部职业故事。

## 反证必须问
- 同一优先权族的后续申请是否被误算为多项同时代发明？
- Google Patents标准化Original Assignee是否把Overture倒填到GoTo时代？
- “观察竞争者”是否被未经审查上升为非法复制？
- 工程提案暂缓是否被写成技术失败？重新使用是否在不同产品场景？
- 该发明人具体开发了什么、是否有署名以外的来源？
- 删除公司自述后，独立证据还剩什么？

## 五体互见
表校时间；书解释流量与广告收益分配；世家揭示专利法律谱系和工程分叉；列传用可证贡献约束英雄叙事；本纪接受其他体裁对变局解释的修订。

## 第八轮补充：世家也应研究史料如何存续
某项技术“世家”的缺失，有时是档案载体从纸、光盘到电子系统迁移造成的，不能用在线专利全文的覆盖状况决定其工程继承是否存在。对US7110993专利的程序CD，我们目前只确认**文献记载附件**，并没有代码或文件目录。对专业人物（列传）更不能将“22,808个文件”全部归到两位专利署名者。

2003 A1与2006 B2关于中间案的不同表述提示：技术法律家族必须有版本的时间维度。参考research/12、13与档案存续协议。
