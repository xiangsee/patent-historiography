# 《企业本纪》编辑标准 v0.1

## 写给谁
面向关心技术、企业和产业发展的普通读者，保留学术可核验性，但不写成专利尽调或方法论文。

## 叙事原则
1. 从可以落实到时间、人物、文件或情境的场景切入；不创造虚构对话和心理活动。
2. 首段提出有历史张力的问题，不能把后来的成功写成早年的宿命。
3. 专利号、IPC、图表藏在证据层，正文只引入理解历史所必需的细节。
4. 使用有层次的长短句，减少机械排比、密集小标题和“资料堆砌”。
5. 不复刻《史记》古文；借其结构与判断尺度。
6. 技术事实、权属事实、经营事实和作者解释分开；重大转折不能只靠专利数量解释。
7. 保留第一人称观察，但不可把推测伪装为亲历。
8. 划线句须由证据支撑，不为金句牺牲真实。

## 正文基本路径
历史现场/反常 → 研究问题 → 技术能力演变 → 决策与组织背景 → 与竞争者比较 → 反证或未竟路线 → 历史评价。

## 首卷目标
Google 1996—2004：一篇4000—6000字正式样稿，另附可复核的史料、时间轴与命题卡。字数是初始编辑建议，可以调整。

## 三重审校
- 数据：样本全集、日期、权属、指标分母、计算与抽样偏差。
- 史实：原始文件、事件顺序、竞争解释、历史人物归属。
- 文字：可读性、节奏、事实与解释区分、引用与版权。
