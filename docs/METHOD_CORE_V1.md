# 《企业史记》方法核心 v1.0候选：压缩而不是增加规则

状态：方法候选。并未通过完整学术全文审阅或全量专利实证。保留五体一库与两层编纂成果。

## 一条主链
历史问题 → 历史主体及尽可能完整的公开专利母集 → 识别可检验的技术能力变化 → 非专利史料与竞争者对照 → 五体互见 → 史家判断 → 可读作品。

历史问题引导研究，**不能**因为知道一个专利故事，就只收集支持它的专利。初始样本应尽量按可观察全集建立，之后才精选历史证据。

## 三项理论基础
1. 《史记》的五体、互见、论赞、史料剪裁、篇章编次：至少把原典和分歧最大的学术解释对读；不需等掌握全部史记学才允许开展方法试验。
2. 企业专利史的关键张力：专利指标不等于全部创新；技术轨迹不等于组织能力；发明者不必然取得最终商业收益。重点对读Griliches/Moser、Dosi/Metzler、Teece及中国企业史学证据。
3. 科学数据与史料批判：历史集团与申请人、简单/扩展同族、优先权与公开、收购/许可、跨法域覆盖及非专利技术，都需要界定可观察边界。

## 五体与长期数据如何真正发生关系
| 体 | 从长期专利数据发现什么 | 必须用什么独立资料核实 |
| --- | --- | --- |
| 本纪 | 技术组合出现、迁移和断裂的候选转折 | 产品、企业组织、产业格局、商业结果 |
| 表 | 专利族/地区/发明人/权属与重大事件并列 | 公司年报、标准、新闻当时档案、竞争者事件 |
| 书 | 产权、标准、研发组织、供应链和知识转化的长期制度安排 | 合同、政策、标准历史、成本、合作网络 |
| 世家 | 技术与组织谱系的可疑继承/分叉/消失 | 工程、研发人员与组织档案，不能只凭IPC/同族 |
| 列传 | 发明人长期参与、团队与关系网络 | 人物独立资料，不能只凭署名与头衔 |

## 四项合理门槛
- M1 学理：核心史学和专利理论的直接论证、反论及其现代转译已形成一份综合方法稿。
- M2 数据：真实企业历史实体和公开专利母集可以按明确的全球/国别范围重现，覆盖缺口已审计。
- M3 解释：至少一项从母集而来、可能被否证的转折，经五体不同任务互相检验和修订。
- M4 写作：形成真实企业五体整书蓝图并通过简明公众叙事测试；然后才写正式首篇。

这些门槛不是要求取得所有原始档案，也不允许因为学术论文或某张光盘拿不到就无限等待。

## “局部线索止损”
同一个单件专利或单案原则上最多连续推进两轮；超过时应回答它改变了什么企业级历史判断、母集边界或五体共同命题。如果不能，就归入专题档案，不再作为下一轮主线。

此原则避免把每个微观谜团都当成完成整部企业史的必要条件。专利仍是基础史料，但**历史而非专利法证是最后的研究对象**。
