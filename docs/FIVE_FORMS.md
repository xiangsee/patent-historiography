# 五体编纂协议 v0.2

五体均为必备研究视角，篇目可以分批出版，但最终整部作品必须有五体。**不能机械照搬12/10/8/30/70篇数，也不按企业股权等级排列历史人物。**

**本纪 BENJI**：以企业在产业中的转折、时代地位和多种路径为主线；需有竞争者与失败路径对照。禁止只罗列创始人履历。

**表 BIAO**：以可核验的时间和多主体对照为中心；优先权、申请、公开、授权、产品、组织、制度、行业事件须分列，附日期精度、来源及当时可知日；独立发现错位、缺口和同时性。申请量曲线不是完整意义上的表。

**书 SHU**：研究产权、许可、标准、研发组织、商业化等制度如何建立、被执行、被挑战及改变；法律条文存在、公司实际实施及经济回报必须分开证明。

**世家 SHIJIA**：须证明可持续的技术/组织谱系与历史继承关系；IPC相同和公司组织架构相似都不足以立世家。可以有分支、断裂、被并购的独立历史。

**列传 LIEZHUAN**：单传、合传、类传、对照传均可；以可核实的人和组织行动为中心，不能用专利署名直接推断动机、分工与实际贡献。

**研究者按**：借鉴“太史公曰”的论赞功能，标明作者结论、其来源、反证、替代解释；不作为第六种并列体例，不冒充司马迁或AI客观定论。

每个篇目关联至少两种其他体例及明确的event_id/claim_id，文本之间重要事实冲突需记录，并在发表前处理或说明争议。具体模板见templates/，学术依据见research/01、02、03。
