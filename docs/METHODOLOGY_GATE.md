## 五体真实测试的判定标准
1. **本纪**是否因表和书出现明确的重新分期或核心判断修订？是，但大势的外部量化证据尚缺。
2. **表**是否发现不同主体/时钟的真实矛盾、而非重排同一张表？是：2000 CPM vs 2002 CPC，并区分2001优先权、2003公开、2010授权。
3. **书**是否独立证明了制度安排影响权利控制或商业化的事实？是：2004专利永久许可及综合和解，实际竞争效果待验证。
4. **世家**是否有真实技术/组织继承证据？否，只有专利族候选与时间先后。
5. **列传**是否有实际贡献与人物的独立资料？否，仅发明人署名与诉讼主体。
