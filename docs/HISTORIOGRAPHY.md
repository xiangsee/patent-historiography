# 从《史记》到现代企业纪传体

## 方法命题
“本纪”不是逐年罗列主角全部事件，而是围绕一段产业秩序如何生成和改变来组织叙事；“互见法”允许同一事件在主线、制度、人物和技术系统之间呈现不同侧面。借鉴的是分析结构，不模拟司马迁的语言或价值秩序。

| 体例 | 现代转译 | 必须回答 |
| --- | --- | --- |
| 本纪 | 企业/行业时间主轴 | 何时发生足以改变后续路径的转折？ |
| 世家 | 技术体系、长期业务与被并购组织 | 能力如何延续、继承或消失？ |
| 列传 | 具可核实贡献的发明人、管理者和竞争者 | 谁做了什么？有何证据？ |
| 书 | 标准、专利、许可、组织及制度 | 技术如何成为可持续的制度性能力？ |
| 表 | 各类事件年表 | 同一时点各条历史线索如何相互影响？ |

## 四条史学戒律
1. **反目的论**：不从今天的成败推定早年的必然性；保留当时信息范围。
2. **反英雄神话**：发明人名单不等于真实协作分工；专利不等于唯一贡献。
3. **反孤立企业叙事**：必须至少选择一个有意义的竞争者或替代路径。
4. **反唯专利主义**：将专利作为可观察的记录，不等同于全部创新与经营活动。

## 章节应有的结构
一处具体且可核验的现场或细节 → 当时的历史问题 → 专利证据及其局限 → 技术、产品、组织、制度对照 → 至少一种竞争解释 → 历史判断及其后果。

## “互见法”实践
若某专利关联大学转让、产品收入和标准竞争：
- 在本纪中回答它在公司命运中的地位；
- 在世家中交代具体技术谱系；
- 在列传中据证据呈现发明人关系；
- 在书中分析许可、权属和标准；
- 在表中记录申请、公开、授权和商业事件的不同日期。

同一事实有唯一可追溯来源ID，章节之间链接命题卡，不重复制造互相矛盾的结论。
