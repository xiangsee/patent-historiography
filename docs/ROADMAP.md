# 研究路线图 / Roadmap

## Phase 0｜2026-11-08：公开研究基线
状态：已启动。创建方法文档、数据契约、证据与章节模板、Google试验入口和研究任务。不声称完成企业全量数据采集。

## Phase 1｜Google 1996—2004：建立可审计数据底座
- 确定集团和历史主体的实体登记表；
- 收集全球专利族并核对授权/公开/优先权、来源差异；
- 披露各年度/地区覆盖与异常值；
- 从SEC及原始专利文件验证首批事件。
验收：清楚说明“全集”的实际含义、缺口与重跑方法。

## Phase 2｜从专利到技术史
- IPC/CPC基础分布、文本聚类、发明人/引用网络；
- 技术—产品—组织—行业四轴时间线；
- 同期竞争者作为对照；
- 至少三个可以否证的转折候选。
验收：可复算图表与至少一条被反证检验过的历史命题。

## Phase 3｜《谷歌本纪》第一章
- 章节方案与证据卡；
- 初稿及反方审稿；
- 交叉核验、公开勘误渠道与正式版。
验收：4–6千字可读正文 + 附录式证据基础设施。

## Phase 4｜华为本纪可行性审计
对多法域数据、历史法人谱系、研发组织变化、非专利信息可得性、对照组与成本作独立评估，决定是否进入完整长期卷；腾讯作为平台型企业比较候选。

## Phase 5｜跨企业、跨产业比较
探索“技术能力形成、迁移、保护与商业化”的通用命题。只有重复验证之后，才能形成比较史结论。

## 原则
每阶段有验收件、反证任务、版本号与公开数据边界；不把长期规划写成既成事实。
