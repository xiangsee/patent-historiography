# 企业本纪 · Patent Historiography

> 用专利作为历史证据，重新书写企业如何形成能力、作出选择、影响产业秩序的历史。

**状态：v0.1.0 / 研究基线（2026-11-08）**  
**开放状态：公开仓库；公开并不等于自由复制所有内容，详见 RIGHTS.md。**  
**首个试验对象：Google，观察窗口 1996—2004；华为与腾讯为后续候选。**

## 这不是“企业专利排行榜”
财务史主要记录已经实现的结果，产品史主要记录市场上看得见的成果；专利则部分保留了成果尚未确定时对技术问题的探索。本项目研究技术能力形成的时间、路径与制度条件，也研究没有进入产品与市场的尝试。

**核心问题：一家企业的历史，不仅包括它最终成为了什么，也包括它曾经有机会成为什么。**

专利是研究入口，绝非全部历史。没有申请专利的发明、商业秘密、组织学习、产品运营和失败实验同样重要。

## 从《史记》借来的不是古文
| 体例 | 本项目中的工作对象 |
| --- | --- |
| 本纪 | 企业与行业变化的主线；识别历史转折 |
| 世家 | 延续性的技术体系、业务组织和并购主体 |
| 列传 | 经过核实的发明人、技术团队与竞争者 |
| 书 | 专利制度、标准、许可、诉讼与组织治理 |
| 表 | 专利—技术—产品—组织—产业多轴年表 |

历史叙事使用现代白话文，避免拟古和结果倒推。史学体例见 docs/HISTORIOGRAPHY.md。

## 五条硬规则
1. **先建可审计的母集，再挑选有故事的专利。** 代表性案例不能冒充全量统计。
2. **区分自主研发、收购、转让、许可和控股。** 今天的权利人不是历史上的发明人或控制者。
3. **分开申请日、优先权日、公开日、授权日和发生日。** 回溯叙事要检查“当时是否可知”。
4. **所有重要叙事判断都连接史料并主动寻求反证。** 不以专利数量直接推出创新成败。
5. **开放成果，不泄露受限原始数据和非公开个人信息。**
