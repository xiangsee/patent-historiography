# 历史命题卡 / Claim Card

- **claim_id**：CLAIM-YYYY-NNN
- **title**：
- **statement**（一句可证伪的判断）：
- **subject_entity**：
- **period_under_study**：
- **knowledge_as_of_date**（当时是否可知）：
- **kind**：fact / data_inference / historical_interpretation
- **status**：HYPOTHESIS / OBSERVED / INFERRED / INTERPRETED / CONTESTED / REJECTED
- **supporting_sources**：source_id + 页码/行号/专利段落 + 支持的具体部分
- **counter_evidence**：source_id + 与命题冲突之处
- **strongest_alternative**：最强替代解释
- **limitations**：地区、法域、专利申请策略、未观察到的资料
- **affected_claim**：本命题影响哪些既有命题
- **impact_type**：support / extend / revise / contradict / new / pending
- **verification_next**：下一项可执行核实任务
- **last_verified_at**：
- **editorial_use**：是否允许进正文，建议表述强度
